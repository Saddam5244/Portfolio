## 🛠️ How to Run Locally

### 1. Development Server (Vite)
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Standalone (Zero-Config)
You can also directly double-click `index.html` or open it with Live Server in VS Code.

### 3. Production Build
```bash
npm run build
```
Creates an optimized static bundle in the `dist/` directory ready for deployment on **Vercel**, **Netlify**, or **GitHub Pages**.
